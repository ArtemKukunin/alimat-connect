# ALIMAT Connect

Внутрішній додаток Alimat Group: кабінети працівника, персоналу, партнера й адміністрації; оголошення, заявки, пам'ятки, база документів, контакт координатора.

- Робоча версія: https://artemkukunin.github.io/alimat-connect/
- Тут лише інтерфейс (статичні файли). Дані, права доступу й тексти пам'яток зберігаються в Supabase і доступні тільки після входу.
- `config.js` містить публічну адресу і публічний (anon) ключ Supabase — це нормально: права перевіряє база (RLS).
